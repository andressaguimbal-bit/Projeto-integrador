PROJETO INTEGRADOR

CENÁRIO N: Plataforma de agendamento de beleza e barbearia

GRUPO: grupo da Andressa

INTEGRANTES: ANDRESSA BORGES e MARIA VITÓRIA BARONI

1.IDENTIFICAÇÃO E VISÃO GERAL:
  A plataforma permitirá que clientes consultem serviços, profissionais e horários disponíveis e realizem agendamentos online. Profissionais poderão visualizar e organizar sua agenda.

2.MODELO DE PROCESSO:
  Será utilizado o modelo incremental, pois permite desenvolver o sistema por partes, entregando funcionalidades aos poucos e realizando melhorias conforme o feedback dos usuários.

3.BACKLOG - USER STORIES:
  
    ID-    USER STORY                                                                                    prioridade
  
    US01- como cliente, quero ver os serviços disponíveis para escolher o que desejo.                    ALTA

    US02- como cliente, quero consultar horários, para escolher um horário disponível.                   ALTA
    
    US03- como cliente, quero fazer agendamento online, para facilitar a marcação.                       ALTA

    US04- como cliente, quero cancelar ou remarcar, para alterar meu horário.                            MÉDIA

    US05- como profissional, quero visualizar minha agenda, para organizar meus atendimentos.            ALTA

    US06- como administrador, quero cadastrar serviços e horários, para manter o sistema atualizado.     MÉDIA

  SPRINT GOAL: Permitir consultar serviços e horários, realizar agendamentos e visualizar a agenda dos profissionais.
  SPRINT REVIEW: Foi entregue uma primeira versão com as principais funções de agendamento.

4.TESTES E QUALIDADE:

   US03-agendamento.
   
   Tipo:teste de sistema.

   DADO QUE existe um horário disponível, quando o cliente confirmar, então o sistema deve registrar o agendamento.
   DADO QUE o horário já está ocupado, quando o cliente confirmar, então o sistema deve informar que está disponível.

   US05- agenda
   Tipo: teste de integração.

   DADO QUE existem agendamentos, quando o profissional acessar a agenda, então os horários devem aparecer corretamente.
   PRINCIPAIS ATRIBUTOS: usabilidade, confiabilidade e segurança.

   5.ÉTICA E PRIVACIDADE:
   
    RISCO:                                            mitigação:
    Exposição de dados pessoais.                      Controle de acesso e proteção dos dados.

    Uso indevido de contatos.                         Permitir acesso somente aos dados necessários.
                           
    Uso de fotos sem autorização.                     Solicitar autorização do cliente.
                       
    Agendamento duplicado.                            Bloquear horários já reservados.
                               
    Falta de transparência.                           Informar quais dados são coletados e utilizados.

    
                             
6.CONSIDERAÇÕES FINAIS: 
 O projeto permitiu aplicar conceitos de Engenharia de Software em uma situação prática. Trabalhamos com o processo incremental, backlog, testes, qualidade, ética e privacidade. A  atividade mostrou que um bom software precisa atender ás necessidades dos usuários, funcionar corretamente e proteger seus dados.
